# نسخه ۰.۳.۲ — ترمینال واقعی

این نسخه به صورت پیش‌فرض از PTY خود VS Code و ConPTY در ویندوز استفاده می‌کند. دستورهای دستی و اجرای فایل پایتون از یک مسیر دریافت ورودی استفاده می‌کنند؛ زبان برنامه محدود به پایتون نیست. نصب مفسر یا کامپایلر زبان همچنان لازم است.

## راه‌اندازی
۱. فایل VSIX را با Extensions: Install from VSIX نصب کنید و Reload Window بزنید.
۲. Shell Integration باید در VS Code فعال باشد (terminal.integrated.shellIntegration.enabled).
۳. در ویندوز PowerShell 7 با نام pwsh یا Git Bash و در لینوکس Bash یا Zsh را انتخاب کنید. اگر شل اولیه powershell قدیمی یا sh باشد، افزونه در صورت نصب‌بودن، یک گزینه سازگار انتخاب می‌کند.
۴. برنامه را اجرا کنید و پاسخ هر سوال را در کادر پایین بفرستید. ورودی‌ها با برچسب کوچک ورودی ثبت می‌شوند؛ بازتاب مستقیم و دقیق همان ورودی در ترمینال حذف می‌شود تا پاسخ دوبار دیده نشود.
۵. برای برنامه‌های تمام‌صفحه، کلیدهای جهت یا ورودی مخفی رمز، از دکمه «ترمینال اصلی» استفاده کنید. نمای فارسی همچنان یک نمایشگر خروجی متنی است، نه شبیه‌ساز کامل صفحه ترمینال.

## رفتار
- هر تب یک ترمینال مستقل دارد؛ مسیر و متغیرهای نشست حفظ می‌شوند.
- توقف، Ctrl+C می‌فرستد؛ برنامه‌ای که آن را نادیده بگیرد ممکن است همچنان اجرا شود. بستن تب، ترمینال را می‌بندد.
- ورودی استاندارد همه برنامه‌ها از مسیر ترمینال واقعی می‌گذرد. برنامه‌های مختلف و تنظیمات شل ممکن است بازتاب ورودی متفاوتی داشته باشند.
- در PTY خروجی عادی و خطا در یک جریان نمایش داده می‌شوند.
- ترمینال بومی مربوط به هر تب در بخش Terminal خود VS Code هم وجود دارد.
- اگر اتصال شل ظرف ۱۰ ثانیه آماده نشود، دستور خودکار اجرا نمی‌شود و ترمینال اصلی برای بررسی باز می‌شود؛ افزونه بی‌صدا به مسیر قبلی برنمی‌گردد.
- گزینه Persian Terminal: Session Backend با مقدار legacy مسیر نسخه قبل را برای تب‌های تازه فعال می‌کند.

## بررسی
ساخت موفق؛ ۷۴ آزمون موفق و یک آزمون مخصوص ویندوز اجرا نشده است.
آزمون‌های PTY با شبیه‌سازی رابط رسمی VS Code انجام شده‌اند: مسیر مشترک دستورها، دو پاسخ فارسی، ترتیب خروجی و پایان اجرا، توقف، بسته‌شدن و نبود Shell Integration.
اجرای واقعی داخل VS Code و ConPTY ویندوز در این محیط قابل آزمایش نبود؛ این نسخه برای بررسی روی سیستم کاربر ارائه شده است.
