# Roadmap after 0.2.0

Completed: persistent per-tab shell sessions; verified shell selection; independent tabs; search; per-run copy/export; live display preferences; Persian RTL rendering; Python file command.

Next priorities:
1. Verify and refine Windows PowerShell 5.1 / PowerShell 7 / Git Bash on real Windows VS Code installations.
2. PTY transport and interruption that preserves the shell; optional full-screen terminal rendering mode.
3. Better support for background jobs and interactive console applications.
4. Broader visual testing for narrow panels, themes, mixed-script tables and accessibility.
5. Optional session profiles and history persistence, with explicit controls for sensitive command history.
