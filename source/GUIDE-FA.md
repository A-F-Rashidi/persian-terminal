# راهنمای Persian Terminal — نسخهٔ ۰.۲.۱

## نصب و شروع

فایل `persian-terminal-0.2.1.vsix` را از بخش Extensions و گزینهٔ **Install from VSIX…** نصب کن. سپس از Command Palette دستور **Developer: Reload Window** و بعد **Persian Terminal: Open** را اجرا کن.

پوشهٔ پروژه باید در VS Code قابل اعتماد باشد. نسخهٔ موردنیاز VS Code برابر ۱.۹۵ یا جدیدتر است. برای نصب افزونه نیازی به نصب Node.js، کامپایل سورس یا نصب جداگانهٔ فونت نیست.

## نشست دائمی

هر تب یک شل مستقل دارد. تغییر مسیر با `cd`، تعریف متغیر، تابع، متغیر محیطی و فعال‌کردن محیط مجازی برای دستورهای بعدی همان تب باقی می‌ماند. پنهان‌کردن پنل یا رفتن به تب دیگر نشست را قطع نمی‌کند.

مثال در PowerShell:

</div>

```powershell
$projectName = 'Logscope'
cd samples
```

<div dir="rtl">

حالا در اجرای بعدی، دستور زیر همان متغیر و مسیر را می‌بیند:

</div>

```powershell
Write-Output $projectName
Get-Location
```

<div dir="rtl">

تغییر شل، بستن تب، Reload Window و بستن VS Code نشست را تمام می‌کنند. در این نسخه نشست‌ها و تاریخچه روی دیسک ذخیره نمی‌شوند.

**دکمهٔ توقف و Ctrl+C فرایندهای نشست را می‌بندند.** دستور بعدی شل تازه‌ای در آخرین مسیر گزارش‌شده باز می‌کند؛ متغیرها و فعال‌سازی محیط مجازی باید دوباره تنظیم شوند. EOF یا Ctrl+D ورودی را می‌بندد و نشست نیز پس از پایان برنامه تمام می‌شود.

## تب‌های مستقل

دکمهٔ **＋** یک تب جدید می‌سازد؛ حداکثر هشت تب هم‌زمان مجاز است. هر تب خروجی، مسیر، تاریخچه و پیش‌نویس ورودی خودش را دارد. می‌توانی هم‌زمان در چند تب برنامه اجرا کنی. روی نام تب دوبار کلیک کن تا آن را تغییر بدهی. × تب را می‌بندد و برنامه‌های آن را متوقف می‌کند.

## انتخاب شل

دکمهٔ نام شل در نوار ابزار فقط شل‌هایی را نشان می‌دهد که در بررسی کوتاه واقعاً اجرا شده‌اند. تغییر این گزینه فقط نشست همان تب را تازه می‌کند. تب بعدی از شل و مسیر تب فعلی شروع می‌شود.

در ویندوز PowerShell، PowerShell 7 و Git Bash نصب‌شده بررسی می‌شوند. انتخاب نام شل باعث نصب آن نمی‌شود. اجراکنندهٔ قدیمی WSL با نام `System32/bash.exe` در فهرست قرار نمی‌گیرد؛ برای محیط لینوکس از VS Code Remote WSL استفاده کن. در لینوکس و macOS گزینه‌های Bash، sh، zsh و PowerShell 7 در صورت نصب بررسی می‌شوند.

اگر مسیر اختصاصی داری، نوع شل و **Persian Terminal: Shell Path** را تنظیم کن و پنجره را Reload کن. شل‌ها بدون بارگذاری پروفایل شخصی شروع می‌شوند.

## اجرای پایتون و ورودی برنامه

فایل را باز کن و از فلش کنار Run گزینهٔ **Run Python File in Persian Terminal** را بزن. این گزینه در راست‌کلیک فایل و Command Palette هم وجود دارد. فایل قبل از اجرا ذخیره می‌شود.

مفسر انتخاب‌شدهٔ افزونهٔ Python استفاده می‌شود. تنظیم **Persian Terminal: Python Path** می‌تواند مسیر اجرایی مفسر را مشخص کند. بدون افزونهٔ Python، ابتدا `.venv` پروژه و سپس Python موجود در PATH بررسی می‌شود.

فایل در **مسیر فعلی تب انتخاب‌شده** اجرا می‌شود و متغیرهای محیطی همان نشست را دریافت می‌کند. هنگام اجرای برنامه، کادر پایین برای `stdin` است؛ مثلاً پاسخ `input()` را در آن بنویس و Enter بزن. وقتی برنامه تمام شود، کادر دوباره دستور شل می‌گیرد.

## جست‌وجو، کپی و ذخیره

**جست‌وجو** یا Ctrl+F نوار جست‌وجوی خروجی تب فعلی را باز می‌کند. نتیجه‌ها مشخص می‌شوند؛ با ↑ و ↓ یا Enter و Shift+Enter بین آن‌ها حرکت کن. Escape نوار را می‌بندد. جست‌وجو به بزرگی و کوچکی حروف حساس نیست و تا ۵۰۰ تطبیق را مشخص می‌کند.

کنار هر اجرا **کپی** و **ذخیره** وجود دارد. این دکمه‌ها خروجی همان اجرا را با ترتیب اصلی نویسه‌ها برمی‌دارند. ذخیره، پنجرهٔ انتخاب فایل را باز می‌کند و متن را با UTF-8 می‌نویسد. دکمهٔ کپیِ بالای پنل، دستورها و خروجی‌های باقی‌ماندهٔ تب فعلی را با هم کپی می‌کند.

خروجی محدود است تا برنامه سنگین نشود: پیش‌فرض ۲۰۰۰ خط و حداکثر ۴۰ اجرای نمایش‌داده‌شده در هر تب. ذخیره و جست‌وجو فقط روی خروجی باقی‌مانده انجام می‌شوند و بخش‌های حذف‌شده بازیابی نمی‌شوند.

## تنظیمات نمایش

روی **نمایش** بزن:

- اندازهٔ فونت از ۱۰ تا ۳۲؛
- فاصله‌های **فشرده** یا **معمولی**؛
- چینش فارسی **راست‌چین**، **چپ‌چین** یا **خودکار**.

تنظیمات همان لحظه اعمال می‌شوند و در تنظیمات VS Code ذخیره می‌شوند. فونت وزیرمتن داخل افزونه است. متن فارسی در حالت پیش‌فرض راست‌به‌چپ و راست‌چین است؛ متن اصلی برای کپی تغییر نمی‌کند.

## پاک‌کردن صفحه

`cls`، `clear` یا `Clear-Host` را به‌تنهایی بنویس؛ خروجی پاک می‌شود ولی متغیرها و مسیر نشست باقی می‌مانند. هنگام اجرای برنامه از دکمهٔ پاک‌کردن یا Ctrl+L استفاده کن؛ نوشتن `clear` در کادر ورودیِ برنامه، همان کلمه را به برنامه می‌فرستد.

## محدودیت‌های این نسخه

این نسخه از pipe استفاده می‌کند و هنوز PTY ندارد. برنامه‌های تمام‌صفحه مثل `nano`، `vim` و `htop`، تکمیل خودکار شل با Tab و کنترل تعاملی jobها پشتیبانی نمی‌شوند. برای آن‌ها از Terminal داخلی VS Code استفاده کن. نمایش خروجی کارهای پس‌زمینه ممکن است به یک اجرای مشخص نسبت داده نشود.

نشست دائمی Bash/sh و رفتار رابط در آزمون‌های خودکار بررسی شده‌اند. اجرای واقعی PowerShell روی ویندوز و بررسی تصویری VS Code در محیط ساخت ممکن نبود؛ نسخهٔ ۰.۲.۱ را ابتدا روی پروژهٔ آزمایشی بررسی کن. گزارش دقیق در `TEST-REPORT.md` است.
